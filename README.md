# 파이썬 필터 카메라
> Python + Pyodide로 만든 모바일 실시간 필터 카메라 앱

---

## ✨ 소개

**파이썬 필터 카메라**는 웹 브라우저에서 동작하는 모바일 카메라 앱입니다.  
Python으로 작성된 이미지 필터를 **Pyodide**를 통해 브라우저에서 직접 실행하여, 서버 없이도 실시간으로 다양한 필터를 적용할 수 있습니다.

## 🎯 주요 기능

### 📷 카메라
- 모바일 카메라(후면/전면) 직접 실행
- 실시간 미리보기
- **촬영 → 필터 적용 → 확인 → 저장**의 직관적 흐름
- **9분할 가이드라인**으로 완벽한 구도 잡기 (토글 가능)

### 🎨 필터 (총 15종)

| 필터 | 설명 |
| :--- | :--- |
| ✨ **원본** | 필터 없이 원본 카메라 |
| 💙 **남색** | 깊고 차가운 푸른빛 |
| 📺 **노이즈** | 흑백 그레인 |
| 🌸 **Y2K** | 핑크빛 레트로 감성 |
| 🟫 **세피아** | 따뜻한 빈티지 갈색톤 |
| ⚫ **흑백** | 모노크롬 명암 |
| 🔄 **반전** | 네거티브 필름 효과 |
| 🔆 **고대비** | 강렬한 명암 대비 |
| ☀️ **따뜻한** | 붉은빛이 도는 따뜻한 톤 |
| ❄️ **차가운** | 푸른빛이 감도는 시원한 톤 |
| 🧊 **픽셀화** | 8x8 블록의 레트로 게임 느낌 |
| 🐟 **어안** | 물고기 눈 렌즈 왜곡 효과 |
| 🔍 **볼록** | 중앙이 확대되는 돋보기 효과 |
| 🔮 **오목** | 중앙이 축소되는 효과 |

### 🗺️ 필터 로드맵
- 각 필터에 **가장 어울리는 사진**을 갤러리에서 업로드
- 여행지 메모와 함께 **자동 저장 (localStorage)**
- 언제든지 수정/삭제 가능

## 📱 모바일 사용 가이드
### 📸 카메라 사용법
1. 페이지 접속 → 카메라 자동 실행
2. 필터 선택 → 좌우로 스크롤하여 원하는 필터 터치
3. 📷 촬영 버튼 → 현재 프레임에 필터 적용 (미리보기)
4. 결과 확인 → 필터 적용된 이미지 확인
5. 💾 저장 버튼 → 필터 적용된 이미지 다운로드
6. ↩️ 다시 촬영 → 카메라로 돌아가서 다시 촬영
7. ⊞ 그리드 → 9분할 가이드라인 On/Off

### 🗺️ 로드맵 사용법
1. 🗺️ 로드맵 버튼 클릭
2. 📤 업로드 버튼 → 갤러리에서 사진 선택
3. ✏️ 메모 → 여행지나 느낌 기록 (자동 저장)
4. 🗑️ 삭제 → 사진 제거
